# Photos des recettes

Dépose ici une image par recette, **nommée avec l'identifiant de la recette** :

```
src/assets/recipes/
  porridge_banane.jpg
  chili_dinde.jpg
  pates_thon.webp
```

Aucun code à modifier : les fichiers sont détectés automatiquement au build.
Les tirets valent les tirets bas et la casse est ignorée, donc
`chili-dinde.jpg` fonctionne aussi.

## Format et poids

JPEG ou WebP, autour de 800 px de large. Ces images partent dans le build : une
photo de 3 Mo alourdit le site pour tous les visiteurs. Vise quelques dizaines
de kilooctets par fichier.

## Droits

N'utilise que des photos dont tu détiens les droits de diffusion : ces fichiers
sont publiés avec l'application.
